# Project resources

Local datasets, model workspaces, caches, environments, generated artifacts, archives, and
workflow history are organized here by project owner or explicit shared status. Large and
patient-level contents are ignored; manifests provide access and hash provenance.

Every resource root and its scientific owner are recorded in `RESOURCE_OWNERSHIP.csv`.
Unregistered datasets, model workspaces, archives, or generic result folders are not
permitted.
