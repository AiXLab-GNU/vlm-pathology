# Prostate biomarker-validation document map

- `designs/`: approved dated study and manuscript designs.
- `plans/`: implementation plans linked to their designs.
- `research_plan/`: canonical hierarchy containing
  `01-prostate-biomarker-validation-plan.md`,
  `01-01-prostate-biomarker-validation-milestones.md`, and
  `01-01-01-prostate-biomarker-validation-execution-tracker.md`.
- `surveys/`: related-work authority index. The maintainable survey is currently `PLANNED`.
- `study_design/`: historical pre-Codex records; closed to new files.
- `CODE_AVAILABILITY.md` and `RUN_REPRODUCTION.md`: stable publication contracts.

New protocols use `docs/protocols/`; superseded narrative belongs in `docs/legacy/`. Do not edit old
records merely to make their names conform to the current style.
