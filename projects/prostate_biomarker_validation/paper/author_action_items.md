must remain partial while any `blocking: yes` item is open.

## Action 1 — Final author list and contributions
blocking: yes
required_value_or_action: Confirm the complete author list and supply one author-approved CRediT role statement covering every named author.

## Action 2 — Competing interests
blocking: yes
required_value_or_action: Obtain an explicit competing-interest declaration for every named author, including an explicit no-interest statement where applicable.

## Action 3 — Funding and acknowledgements
blocking: yes
required_value_or_action: Confirm all funders, grant identifiers, funder roles and non-author assistance, or explicitly confirm that none apply.

## Action 4 — Ethics, institutional determination and consent
blocking: yes

## Action 5 — Derived-data deposition
blocking: yes

## Action 6 — Code release
blocking: yes
required_value_or_action: Decide whether code may be released, approve the release licence and archive, and provide the permanent repository URL or DOI and any restrictions.
