# Prostate biomarker manuscript bundle

This directory is a controlled submission bundle. Existing manuscript, figure-data,
renderer, manifest, and generated-output paths are stable provenance contracts.

- manuscript sources and declarations remain at their existing canonical paths;
- figures must be generated from saved source tables;
- generated files are not hand-edited;
- new revision notes go under `revision/` with dated lowercase-kebab-case names;
- filename cleanup is deferred unless a submission migration updates every reference and
  records pre/post hashes.

Canonical reviewer-workflow documents are `stanford-review.md`,
`revision-prompt-tier-1-2.md`, and `tier-1-2-response-summary.md`. Older spellings remain
only in closed historical inventories and the rename map.
