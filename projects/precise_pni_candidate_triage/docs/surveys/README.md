# PRECISE PNI survey index

관련연구는 신규성, baseline, 방법 선택과 claim boundary를 정하는 연구계획의 공식 입력이다.
현재 이 프로젝트에는 검색 protocol과 포함·제외 기준을 갖춘 canonical survey가 없다. 이를
숨기지 않고 `PLANNED`로 관리하며, 문헌 내용을 새로 조사하기 전에는 최신성이나 신규성을
주장하지 않는다.

| 문서 | 역할 | 상위 입력 | 후속 결정 | 권위 상태 |
|---|---|---|---|---|
| `pni-candidate-triage-related-work-survey-ko.md` (미작성) | candidate triage, morphology phenotyping, contour quantification 관련연구 종합 | [연구계획](../project_plan/01-precise-pni-project-plan-ko.md) | baseline·확장 코호트·claim boundary 재검토 | PLANNED |

허용 상태는 `PLANNED`, `CURRENT`, `SUPPORTING`, `HISTORICAL`, `SUPERSEDED`이다.
`CURRENT` 문서가 생기면 연구계획에서 직접 링크하고, `SUPERSEDED` 문서는 이 표에서 대체
문서를 반드시 링크한다.
