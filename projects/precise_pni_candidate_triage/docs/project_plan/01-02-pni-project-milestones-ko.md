# PRECISE PNI 프로젝트 마일스톤

이 문서는 [상위 연구계획](01-precise-pni-project-plan-ko.md)을 work package와 evidence
gate로 분해한다. 연구 질문, 성공 기준, claim boundary를 독자적으로 변경하지 않는다.
현재 운영 상태와 단일 다음 작업은
[실행 추적표](01-02-01-pni-project-execution-tracker-ko.md)에서 관리한다.

| 마일스톤 | 상태 | 핵심 산출물 | 완료 또는 진입 gate |
|---|---|---|---|
| M0 연구 범위·재현성 기반 | 완료 | 프로젝트 경계와 재현성 계약 | candidate-triage 범위 확정 |
| M1 후보 생성·120건 판독 세트 | 완료 | frozen candidate universe와 review set | score·좌표·NMS 고정 |
| M2 frozen-score 감사 | 완료 | audit tables와 보고서 | 120건 reconciliation 통과 |
| M3 14-focus 형태 재판독 도구 | 완료 | blinded review package | fixed 14-focus set 재현 |
| M4 형태 재판독 수령·무결성 | 완료 | locked review와 conflict audit | 결측·불확실성 보존 |
| M5 공식 잠금·contour 대상 | 완료 | eligibility/adjudication 기록 | contour 대상과 보류 대상 분리 |
| M6 전문의 contour·adjudication | 진행 | contour package와 승인 기록 | 실제 browser/QuPath dry run 및 전문의 승인 |
| M7 형태계측·공간 분석 | 잠금 | contour 기반 source tables | M6 승인 contour 필요 |
| M8 확장 코호트 운영 검증 | 계획 | 별도 승인된 review workflow | 독립 설계·전문의 판독 필요 |
| M9 임상·분자·예후 분석 | 장기 계획 | 환자 단위 분석 | 표본수·endpoint·독립 검증 필요 |
| M10 외부검증·논문화 | 장기 계획 | claim-evidence audit와 manuscript | 앞선 claim gate 통과 필요 |

세부 근거와 태스크는 [상위 연구계획](01-precise-pni-project-plan-ko.md)에 보존한다.
이 마일스톤 문서는 `MILESTONES.md`의 요약 인덱스보다 높은 운영 권위를 갖지만 연구계획보다
상위가 아니다.
