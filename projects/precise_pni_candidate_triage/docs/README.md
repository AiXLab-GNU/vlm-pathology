- `designs/`: approved study designs; dated `-design.md` files with metadata.
- `plans/`: implementation plans linked to an approved design.
- `pathologist_protocol/`: frozen clinician-facing review instructions and schemas.
- `project_plan/`: active hierarchy rooted at
  `01-precise-pni-project-plan-ko.md`; `01-01-pni-research-overview-ko.md` is a child
  research narrative, `01-02-pni-project-milestones-ko.md` is the canonical milestone
  refinement, and `01-02-01-pni-project-execution-tracker-ko.md` records current operations.
- `surveys/`: related-work authority index. No `CURRENT` survey is presently registered.

The descriptive PNI research overview is
`project_plan/01-01-pni-research-overview-ko.md`.

Results belong in `../reports/`; manuscript prose belongs in `../paper/`. The current
validated role is candidate triage for pathologist review, not whole-slide diagnosis.
