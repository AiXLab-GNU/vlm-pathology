# PRECISE PNI Candidate Triage

이 프로젝트는 frozen score로 공간적으로 구분된 PNI 후보 영역을 순위화하여 병리의
검토를 돕는다. 현재 시스템은 whole-slide PNI 진단기가 아니며 임상적으로 검증되지
않았다.

주요 분석은 frozen-score audit, 14개 nerve-positive focus의 blinded morphology
re-review, 병리의 contour review와 candidate visualization이다.

프로젝트 진행 순서는 [`00-project-sequence/`](00-project-sequence/)에서 번호순으로
확인한다.
