# Quantitative foundation-model validation survey index

관련연구는 연구계획의 공식 입력이지만, 현재 유지보수 가능한 canonical survey와 과거
탐색 기록을 구분한다. 아래 `HISTORICAL` 문서는 기존 연구 방향 형성에 참고되었으나 파일명,
검색 protocol, source audit를 현재 규정에 맞춰 개정하지 않았으므로 `CURRENT`로 승격하지
않는다.

| 문서 | 역할 | 상위 입력 | 후속 결정 | 권위 상태 |

허용 상태는 `PLANNED`, `CURRENT`, `SUPPORTING`, `HISTORICAL`, `SUPERSEDED`이다.
`CURRENT` 문서는 연구계획에서 직접 링크하며, `SUPERSEDED` 문서는 대체 문서를 이 표에서
링크한다. 실제 문헌 감사 전에는 최신성·신규성·우월성을 주장하지 않는다.
