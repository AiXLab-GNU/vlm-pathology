# Quantitative Foundation-Model Validation

의료 정량지표가 CONCH와 Virchow 표현에서 복원되는지(H1), 그리고 독립적인 질병
endpoint 예측에 해당 지표 관련 표현이 기능적으로 사용되는지(H2)를 단계적으로
분리해 검증한다.

현재 완료 범위는 P0 및 FM1–FM3이며 FM4는 제한적 exploratory/descriptive concept
benchmark의 연구책임자 승인 대기 상태다.

P0부터 FM/H2까지의 진행 순서는 [`00-project-sequence/`](00-project-sequence/)에서
번호순으로 확인한다.
